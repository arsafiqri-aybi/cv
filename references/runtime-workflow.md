# Runtime Workflow

```text
USER REQUEST
↓
JOB CLASSIFICATION
↓
TARGET ROLE MODEL (if applicable)
↓
CANDIDATE EVIDENCE INVENTORY
↓
EVIDENCE ↔ REQUIREMENT MAP
↓
GAP DIAGNOSIS
↓
CLAIM CALIBRATION
↓
SIGNAL SELECTION
↓
DOCUMENT CONSTRUCTION
↓
HUMAN AUDIT
↓
MACHINE AUDIT
↓
INTEGRITY / FAIRNESS AUDIT
↓
FINAL OUTPUT
```

For small rewrites where evidence is explicit, preserve facts, calibrate wording, rewrite, and run a lightweight integrity check.

Use the deep path for complete CV creation, major tailoring, career change, executive/technical CVs, contested evidence, ATS concerns, or scientific audit.
