# Candidate Discovery Output Contract v1.0

Output:
1. Master Candidate Summary
2. Episode Inventory with coverage state
3. Normalized Evidence Records
4. Skill / Tool / Domain Index linked to evidence where possible
5. Provenance / Artifact Index
6. Open Material Gaps
7. Deferred Optional Topics

Persist asked intents, answered intents, known facts, contradictions, and coverage states.

Completion means major history is discovered, material episodes are CV_USABLE, no unresolved P0 blocker remains, and current target deltas are handled if applicable.

It is not necessary to exhaust every possible anecdote.
