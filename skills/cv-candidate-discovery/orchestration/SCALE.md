# Candidate Discovery Scale Contract

CD0 State load — existing evidence, prior interview state, preferences, target application.
CD1 Timeline discovery — discover major episodes broadly.
CD2 Episode evidence — bring material episodes to CV_USABLE with bounded probes.
CD3 Cross-episode index — skills, tools, domains, credentials, artifacts.
CD4 Outcome/provenance enrichment — ask only where useful.
CD5 Target delta — resolve material target-specific gaps only.
CD6 Consistency — resolve P0 contradictions and chronology conflicts.
CD7 Handoff — Master Candidate Evidence Base + unresolved material gaps + state.

Replan when a new major episode appears, chronology breaks, target changes, repeated questioning indicates memory failure, or burden rises without useful evidence.
