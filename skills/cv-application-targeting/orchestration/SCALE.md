# Application Targeting Scale Contract

## AT0 — Target lock
Resolve target application identity and available sources.

## AT1 — Vacancy model
Extract requirements, importance, hardness, terminology, context.

## AT2 — Role model
Separate durable role/work reality from employer-specific wording.

## AT3 — Evidence retrieval
Retrieve relevant candidate evidence from the master evidence base.

## AT4 — Mapping
Map evidence to requirements without forcing matches.

## AT5 — Gap diagnosis
Identify hard constraints and evidence/transferability gaps.

## AT6 — Tailoring plan
Select, omit, reorder, emphasize, align terminology, contextualize.

## AT7 — CV variant construction
Apply root CV claim calibration and document-structure rules.

## AT8 — Verification
Run factual, human, machine, consistency, and targeting audits.

## Replan triggers
- vacancy source changes materially;
- target role changes;
- hard constraint discovered;
- company context contradicts prior assumption;
- candidate evidence changes;
- tailoring requires unsupported claims.
