# Document Structure Master Prompt

Build the CV's document structure as a semantic encoding system, not a template-selection exercise.

## Mission

Transform already-calibrated candidate evidence into a document whose:
- section architecture;
- ordering;
- entry grouping;
- typography;
- spatial hierarchy;
- page flow;
- reading order;
- PDF structure

support accurate human and machine interpretation.

## Protected constraints

- facts and claim calibration remain upstream authority;
- structure may prioritize evidence but may not change evidence;
- no universal one-page rule;
- no universal font-family rule;
- no universal section order;
- no universal one-column/two-column claim;
- visual appeal cannot override legibility or extraction integrity;
- parser success is not ranking success.

## Route

```text
CONTEXT
→ SECTION CANDIDATES
→ SECTION INCLUSION
→ INFORMATION PRIORITY
→ SECTION ORDER
→ ENTRY STRUCTURE
→ TYPOGRAPHIC HIERARCHY
→ PAGE FLOW
→ MACHINE/PDF STRUCTURE
→ HUMAN AUDIT
→ EXTRACTION AUDIT
→ FINAL STRUCTURE
```

## Completion

The structure is complete only when:
- strongest relevant evidence is easy to locate;
- semantic groups are visually and logically coherent;
- page density is controlled;
- final export preserves text and reading order;
- no major parser/accessibility failure is detected.
