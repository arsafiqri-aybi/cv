# Document Structure Scale Contract

## DS0 — Context lock
Resolve role, candidate stage, document type, platform, region, evidence volume.

## DS1 — Research map
Maintain CV-specific, adjacent document-science, parser, and standard evidence separately.

## DS2 — Section architecture
Decide inclusion and section purpose.

## DS3 — Priority architecture
Decide order and within-section evidence priority.

## DS4 — Entry architecture
Define role/project/education grouping and bullet structure.

## DS5 — Visual hierarchy
Typography, spacing, alignment, density, visual grouping.

## DS6 — Page architecture
Page length, breaks, continuation, single/multi-column.

## DS7 — Machine/accessibility structure
Reading order, section semantics, extraction, PDF.

## DS8 — Artifact verification
Human visual QA + text extraction + association QA.

## Replan triggers
- evidence volume makes current page plan illegible;
- export changes reading order;
- machine extraction corrupts associations;
- career context changes;
- known submission system imposes constraints;
- document type changes to academic CV.
