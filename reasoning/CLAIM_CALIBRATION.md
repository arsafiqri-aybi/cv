# Claim Calibration v1

## Purpose

Control how strongly the CV may state something.

## Claim ladder

### L0 — Omit
Use when:
- unsupported;
- irrelevant;
- materially misleading;
- too sensitive;
- contradicts stronger evidence.

### L1 — Descriptive
Neutral factual statement.

Example pattern:
`Worked with X on Y.`

Use when:
- the fact is relevant;
- contribution/outcome is unclear;
- stronger inference would exceed evidence.

### L2 — Bounded contribution
States contribution without claiming sole causality.

Example pattern:
`Contributed to X by doing Y, supporting Z.`

Use for shared/team contexts.

### L3 — Direct contribution
States direct ownership of an action/output.

Example pattern:
`Built X to enable Y.`

Requires clear attribution.

### L4 — Outcome-linked
Links contribution to a measured/observed outcome.

Example pattern:
`Built X, reducing reporting time from A to B.`

Requires:
- real metric;
- understood baseline;
- defensible attribution;
- provenance.

### L5 — Causal/leadership-strength claim
High-risk wording such as:
- drove;
- caused;
- transformed;
- led company-wide;
- increased revenue by X%.

Requires substantially stronger evidence and attribution.

## Verb rule

A stronger verb is a stronger claim.

Do not replace:
- helped → led;
- participated → owned;
- used → mastered;
- supported → transformed

without evidence.

## Metric rule

Quantification can improve specificity but can also create false precision.

Metrics must be:
- real;
- relevant;
- interpretable;
- attributable.

## Compression rule

When shortening, preserve:
1. actor/contribution;
2. what was produced/done;
3. most diagnostic context/outcome.

Do not compress away caveats that materially prevent overclaiming.
