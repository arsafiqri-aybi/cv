# Construct Taxonomy v1.0

## Status

This is an **operational taxonomy snapshot**, not a claim that CV science naturally contains this exact number of constructs.

The taxonomy was derived from:
- the process architecture;
- breadth-first literature discovery;
- claim/contradiction/uncertainty registries;
- construct candidates;
- boundary and non-edge analysis.

## Membership rule

A node receives one primary region for retrieval. Cross-region edges represent scientific/operational relationships.

Primary membership is an indexing decision, not a claim of ontological isolation.

## Promotion rule

A construct remains in v1 only if it:
1. has a clear operational definition;
2. is distinguishable from neighboring constructs;
3. improves reasoning, retrieval, validation, or output quality;
4. is not merely a stylistic synonym;
5. does not collapse an important non-edge.

Counts are version metadata, not scientific quality metrics.
