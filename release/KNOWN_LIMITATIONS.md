# Known Limitations — v1.0

## Scientific
- Literature mapping is breadth-first, not a systematic review.
- Scientific saturation is not claimed.
- Modern AI/LLM hiring findings are emerging and system-specific.
- Holistic résumé criterion validity remains an important open question.
- Achievement/quantification diagnosticity is not fully established.
- Tailoring evidence is not isolated from writing-quality effects across all contexts.

## Context
- Cross-cultural conventions are under-developed.
- Legal requirements are jurisdiction-specific.
- Academic CVs, executive CVs, and highly creative occupations need additional depth.
- Production ATS behavior varies and is often proprietary.

## Evaluation
- The repository contains static and behavioral test definitions.
- A test definition is not an independently executed model evaluation.
- Real-world callback outcomes are noisy and not causal proof.
- Independent recruiter validation has not been conducted.

## Runtime
- The Skill cannot verify facts absent from user/source evidence.
- The Skill cannot guarantee interviews, offers, performance, or ATS ranking.
- Parseability must be tested on actual produced artifacts when they exist.

## Release claim
v1.0 means the architecture, schemas, graph, reasoning, audits, evaluation definitions, runtime Skill, and release controls exist. It does not mean universal scientific completeness.
