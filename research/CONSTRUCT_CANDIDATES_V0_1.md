# Construct Candidates v0.1

These are **candidate constructs**, not frozen modules.

Promotion requires:
- clear definition;
- evidence anchor;
- boundary from neighboring constructs;
- measurement/outcome mapping;
- operational usefulness.

## Region A — Role / Work Reality

Candidates:
- work activity;
- task;
- work output;
- responsibility;
- worker attribute / KSAO;
- competency;
- work context;
- seniority / level;
- minimum requirement;
- preferred requirement;
- credential constraint;
- role terminology;
- requirement importance;
- requirement evidence source.

Critical boundaries:
- task ≠ skill;
- skill ≠ credential;
- responsibility ≠ outcome;
- JD statement ≠ verified work requirement.
